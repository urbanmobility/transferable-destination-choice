# Registered hypotheses

Files as written at registration and test time (original statements in Chinese; `registry_en.csv` gives them in English).

| File | Content |
|---|---|
| `registered.json`, `results.json` | first set, batches 1–2 (H1-01…H2-05): registered hypotheses and held-out results |
| `registered_extra.json`, `results_extra.json` | first set, batch 3 (H3-01, H3-02; flexible model) |
| `registered_v3.json`, `results_v3.json` | first set, batch 4 (H4-01…H4-03; library formulas) |
| `registered_p7.json`, `results_p7.json` | second set (P7-01…P7-10), registered after the freeze |
| `registry_en.csv` | English statements and results of all 25 hypotheses (Additional file 1, Table S3) |

Formula identifiers such as
`c0355r1` (Reach model), `c0262` (Tempered power law) and `c0514c1` (Two-regime power law) refer to `../freeze/pool.json`.
